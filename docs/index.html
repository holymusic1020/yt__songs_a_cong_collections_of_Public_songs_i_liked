About

Nix Speech is an independent music project publishing one original song every day. Every track is written, produced and voiced by the project itself, then released automatically to its own channels.

Listen  ·  youtube.com/@nixspeech

Where the music appears

  • YouTube — full videos and Shorts, one release per day
  • TikTok — @nixspeech
  • Facebook — the Nix Speech Page

The publishing pipeline

Releases are produced by an automated pipeline operated solely by the artist. It publishes only the artist's own original work, and only to the artist's own accounts. It never posts on behalf of any other person, never reads other users' content, and never messages or follows anyone.

The pipeline connects to TikTok through the official TikTok Content Posting API using OAuth consent granted by the artist, and only after the artist has authorised it in person.
