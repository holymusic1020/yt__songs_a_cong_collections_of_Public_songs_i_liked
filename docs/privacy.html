Privacy Policy

The Nix Speech TikTok integration exists for a single purpose: posting short music videos, created by the account owner, to the owner's own TikTok account via the TikTok Content Posting API.

Data we access

  • user.info.basic — open id, display name and avatar of the owner's TikTok account.
  • video.upload / video.publish — publish permission only. We never read the videos, analytics or personal data of any other user.

Data we store

  • OAuth refresh and access tokens for the owner's own account, stored as encrypted secrets in a private GitHub Actions secret store and rotated automatically.
  • No cookies, no tracking, no analytics on TikTok users, and no sale or sharing of any data with third parties.

Third parties

  • TikTok for Developers (OAuth + Content Posting API) — the only processing counterpart. No other third-party SDKs are used.
  • GitHub Actions — runs the publishing pipeline on a schedule.

Owner rights

The operator (the account owner, and the only data subject) may revoke access at any time from the TikTok app → Settings → Privacy → Apps, or by deleting this app in the TikTok developer portal. All stored secrets are destroyed on deletion.

Data retention

Tokens are retained only while the integration is active, and are replaced automatically on each rotation. No personal data is retained beyond what the API returns for the owner's own account.
